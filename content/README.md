# Content Folder

Drop your PDF documents into the appropriate subfolder:

## `/kf-lessons/`
All 52 weekly KF lesson PDFs. Name them like:
- `KF00.pdf`, `KF01.pdf`, `KF02.pdf` ... `KF52.pdf`

## `/toolbox/`
All toolbox and meditation documents (~20-30 PDFs).

## `/nhg/`
All NHG book study materials (reading guides, schedules, facilitator docs).
